LUSOL.LUSOLFactorization — Type
LUSOLFactorization <: Factorization{Float64}

Factorization object returned by LUSOL.lu(A). Supports property access (F.L, F.U, F.p, F.q, F.Rs), iteration/destructuring, issuccess(F), and linear solves via F \ b.

LUSOL.crtLUSOLparm — Method
crtLUSOLparm(; kwargs...) -> LUSOLparm

Creates and initializes a LUSOLparm object with default LUSOL settings. Any parameter can be overridden via keyword arguments.

Keyword Arguments

  • nout::Int = 6: Output unit number (6 = stdout).
  • print_level::Int = 0: Print level (0 = silent, 10 = debug).
  • maxcol::Int = 5: Max columns searched in Markowitz pivoting.
  • pivoting::Symbol = :TPP: Pivoting strategy (:TPP, :TRP, :TCP).
  • keepLU::Bool = true: Retain L and U factors (true = 1, false = 0).
  • Ltol1::Float64 = 10.0: Max multiplier allowed in L during factorization.
  • Ltol2::Float64 = 10.0: Max multiplier allowed in L during updates.
  • small::Float64 = 3.0e-13: Drop tolerance for small elements.
  • Utol1::Float64 = 3.7e-11: Absolute tolerance for small pivots in U.
  • Utol2::Float64 = 3.7e-11: Relative tolerance for small pivots in U.
  • Uspace::Float64 = 3.0: Factor for memory expansion.
  • dens1::Float64 = 0.3: Threshold for switching to dense LU.
  • dens2::Float64 = 0.5: Secondary dense threshold.
  • lena_factor::Float64 = 2.0: Initial buffer multiplier for lena.

extrLU(parm::LUSOLparm, objA::LUSOLobjA, res::LUSOLres) -> Tuple{SparseMatrixCSC{Float64, Int}, SparseMatrixCSC{Float64, Int}}

LUSOL.lu6sol — Method
lu6sol(parm::LUSOLparm, objA::LUSOLobjA, res::LUSOLres, b::Vector{Float64}; mode::Int = 5) -> Vector{Float64}

Solves a linear system using the factorization stored in (parm, objA, res).

Modes

  • 1: Solve L * v = b (v has length m)
  • 2: Solve L' * v = b (v has length m)
  • 3: Solve U * x = b (b has length m, x has length n)
  • 4: Solve U' * x = b (b has length n, x has length m)
  • 5: Solve A * x = b (b has length m, x has length n) [default]
  • 6: Solve A' * x = b (b has length n, x has length m)
